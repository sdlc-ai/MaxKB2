SMTP 登录体验优化

当前问题与改进方案对比

📍 当前登录流程

1
用户输入账号密码
用户填写用户名和密码，点击登录
2
⚠️ 突然弹出"验证码已发送"
用户没有预期到需要邮箱验证码，不知道发到哪个邮箱
3
⚠️ 无重发按钮
如果邮件丢失或延迟，用户无法重新发送验证码
4
⚠️ 需要二次操作
用户去邮箱查看验证码后，需要重新输入并提交

方案 A：轻量优化

保持两步流程，优化用户体验

✓ 开发量小，快速实现
✓ 添加重发按钮和倒计时
✓ 显示邮箱地址提示
✓ 状态提示更友好
✗ 仍需两步操作
推荐 工作量小

方案 B：单页整合

在同一页面完成所有操作

✓ 一次性输入账号+密码+验证码
✓ 流程更连贯
✓ 减少用户等待
✗ 需要提前知道邮箱
✗ 首次登录体验复杂
工作量中

方案 C：自动填充

后端自动填入邮箱验证码

✓ 最流畅的体验
✓ 用户无需手动输入验证码
✗ 需要后端轮询或 WebSocket
✗ 开发量大
✗ 安全性考量
工作量大
